# Locked narration

**Status:** LOCKED — 2026-07-14  
**Voice:** Kokoro `af_heart`, speed 1.1  
**Music:** none

## S1 — Question

How does a question become a clear narrated explainer, while every word,
motion, and second stays inspectable?

## S2 — Context

This skill treats video as teaching, not advertising. It sets context, walks
through three visible steps, then explains the result.

## S3 — Step 01: research and lock

First, authoritative sources support each claim. One idea is assigned to each
scene. Then narration locks, so pictures cannot rewrite the explanation.

## S4 — Step 02: synthesize and measure

Next, Kokoro creates one wave file per scene. Each is measured. Those
durations determine scene starts, audio cues, and breathing room. Timing is
evidence, not a guess.

## S5 — Step 03: compose as source

Measured durations drive readable HTML. CSS sets design, SVG draws diagrams,
and GSAP adds seek-safe motion. Unique audio IDs and local assets make the
render reproducible.

## S6 — Validate, render, enable

Finally, HyperFrames lints and checks. Midpoint snapshots are inspected before
rendering. FFprobe, loudness, and final frames verify the result. Corrections
become edits and rerenders.

## S7 — Recap and credit

Recap: source, lock, measure, compose, verify. The whole video remains
editable source. Method credit: Idan Shimon.
