# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities using GitHub's private vulnerability reporting feature on this repository.

## Scope

**In scope:**
- `install.sh`
- `skills/explainer-video/scripts/smoke_test.sh`
- The `SKILL.md` instructions themselves (e.g., anything that could cause an agent following them to run unsafe commands)

**Out of scope:**
- Upstream tools (HyperFrames, FFmpeg, Kokoro). Please report those upstream.

## Expected Response Window

We aim to acknowledge receipt of vulnerability reports within 3 business days and provide an update on the resolution plan within 7 business days.
